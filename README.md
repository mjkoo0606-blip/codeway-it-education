# 코드웨이 IT 교육센터 홈페이지

IT 전문 교육기관 홍보용 반응형 홈페이지 과제입니다.

## 실행 방법
1. `index.html` 파일을 브라우저에서 열면 됩니다.
2. 또는 VS Code에서 Live Server 확장 프로그램으로 실행합니다.

## 포함된 교육과정
- 프론트엔드 웹 개발 과정 (HTML/CSS, JavaScript, React)
- AI 서비스 개발 과정 (Python, LLM, RAG)
- 백엔드 및 데이터베이스 과정 (Java, Spring, MySQL)

## 기능
- 반응형 홈페이지 디자인
- 모바일 내비게이션 메뉴
- 교육과정 소개 카드
- 상담 신청 체험용 양식 (실제 데이터 전송 없음)
